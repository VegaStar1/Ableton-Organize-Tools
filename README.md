# Debridr

Debridr (читается «дебридер», от хирургического «дебридмент»: удаление отмершего) — настольная программа для Windows и macOS. Показывает, какие плагины и сэмплы реально используются в ваших проектах, находит лишние форматы плагинов (VST2, AAX рядом с VST3) и неиспользуемые файлы, и позволяет убрать их безопасно: через корзину внутри программы.

## Что умеет

- **Выбор DAW.** Ableton Live, Studio One, FL Studio, Pro Tools, Bitwig, Cubase, REAPER, Logic. Установленные находятся сами. Плагин считается нужным, если он используется в проектах любой выбранной DAW.
- **Плагины.** Сканирует стандартные папки VST3, VST2, AAX, CLAP, AU и ваши дополнительные. Объединяет форматы одного продукта и показывает, в каких проектах нужен каждый формат.
- **Проекты.** Список плагинов в каждом проекте, потерянные файлы, плагины, которых нет на диске.
- **Сэмплы.** Быстрый просмотр библиотек (терабайты), цвет по состоянию: нужен / только в старых проектах / нигде / часть проекта. Переход по папкам, выбор неиспользуемого.
- **Дубликаты.** Точные копии файлов (BLAKE3), читаются только кандидаты с одинаковым размером.
- **Правая кнопка мыши.** Показать в проводнике, скопировать путь, прослушать сэмпл, запустить деинсталлятор плагина из «Приложений» Windows, найти плагин в интернете.
- **Прослушивание.** WAV, MP3, FLAC, OGG, M4A прямо в программе. AIFF и REX встроенный плеер не играет.
- **Картинки плагинов.** Если плагин сам содержит снимок интерфейса (VST3 Snapshots) или обложку Native Instruments NKS, она показывается при наведении.
- **Кэш.** В настройках можно очистить кэш проектов и журнал ошибок. Настройки, папки и корзина остаются.
- **Корзина.** Всё убранное переезжает в скрытую папку на том же диске (мгновенно). Оттуда можно вернуть на прежнее место, удалить отдельный файл или очистить всю корзину.

## Как программа решает, что можно убрать

Принцип: **сомневаешься, оставь.**

| DAW | Как читается проект | Что известно точно |
|---|---|---|
| Ableton Live | разбор `.als` (XML) и пресетов User Library | формат плагина (VST3/VST2/AU) и пути к файлам |
| Studio One, FL Studio, Pro Tools, Bitwig, Cubase, REAPER | поиск названий установленных плагинов и путей к аудио внутри файла | формат неизвестен |
| Logic Pro | не читается | плагины AU не предлагаются к удалению |

- Если формат неизвестен, защищаются **все** форматы, которые эта DAW умеет загружать (настройка «Безопасно»). AAX освобождается, если Pro Tools не выбран.
- Старый проект с Serum VST2 не найдёт Serum VST3 сам. Поэтому VST2 помечается как «нужен», пока такой проект существует.
- Если сэмпл в проекте указан по старому пути, но файл с таким именем есть в библиотеке, он считается используемым.
- Файлы внутри папки проекта (`Samples/Recorded` и т. п.) считаются частью проекта и не предлагаются к удалению.
- Сервер перепроверяет каждый запрос на удаление по последнему скану. Интерфейсу не доверяется.
- Перед перемещением в корзину программа проверяет, что ни один проект не появился и не изменился после скана, а сам файл не изменился. Иначе просит пересканировать.
- Строгая защита (по умолчанию): файл с тем же именем, что встречается в любом проекте, считается нужным, даже если проект ссылается на другую папку.
- Пресеты Ableton (`.adg`, `.adv`, `.alc`), лежащие внутри библиотек сэмплов, читаются как проекты: сэмплы, которые они используют, остаются.
- Вывод «не используется» верен только для просканированных папок проектов. Добавьте все папки, включая архив.

## Структура

```
core/        движок на Rust: DAW, плагины, парсеры проектов, индекс сэмплов, анализ, корзина, CLI
src-tauri/   оболочка Tauri 2 (команды между интерфейсом и движком)
ui/          интерфейс без сборки (HTML/CSS/JS). В обычном браузере работает на демо-данных
```

## Запуск

Движок и консольная версия (работают везде, где есть Rust):

```bash
cargo test -p organizer-core
cargo run --release -p organizer-core --bin organizer-cli -- scan --daws ableton,studioone --projects "D:\Projects" --samples "D:\Samples"
```

Приложение с окном:

```bash
cargo install tauri-cli --version "^2" --locked
cargo tauri dev
cargo tauri build
```

Портативная версия для Windows без установщика: `cargo build --release -p debridr` даёт один `.exe`, интерфейс встроен в него. Её же собирает GitHub Actions при каждом пуше: вкладка Actions → последний запуск `windows-portable` → архив `Debridr-windows-portable` внизу страницы. Нужен WebView2, он есть в Windows 10 и 11. Сборка для macOS временно отключена.

## Известные ограничения

- Версия для macOS собирается, но не проверена на реальном компьютере.
- Studio One, FL Studio, Pro Tools, Bitwig, Cubase и REAPER читаются по названиям. Это безопасно, но менее точно, чем Ableton.
- Размер плагина считается по самому плагину, без библиотек и пресетов, которые он ставит отдельно.
- Плагины в `Program Files` может потребоваться убирать, запустив программу от имени администратора.
